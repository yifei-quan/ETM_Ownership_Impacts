## Reading the results

The SI provides data construction, equations, and interpretation. These files contain the complete supporting displays. Figure PDFs preserve the source artwork as vector graphics, and the PNGs provide high-resolution previews. Table CSVs preserve the displayed precision and significance markers.

The efficiency regressions report a sample of 1,280 projects (524 domestic-owned and 756 foreign-owned). All figures and tables preserve the final results in the source SI.

This repository contains supporting displays and aggregate results. Raw S&P, Orbis, and DHS records are not included.
