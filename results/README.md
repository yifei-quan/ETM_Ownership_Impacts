# Table result files

These files preserve the final table values and displayed precision in the source SI. Figure data are not included.

- **outcome_summary.csv**: units, temporal coverage, project-year analytical observations, and descriptive statistics before standardization and sign orientation; identical to the table CSV.
- **efficiency_regressions.csv**: the complete displayed efficiency regression table, including standard errors, significance markers, fixed effects, and sample sizes; identical to the table CSV. The dependent variable is efficiency in columns 1–2 and its natural logarithm in columns 3–4.
- **matched_sample.csv** and **spatial_attribution.csv**: numeric transcriptions of the complete tables at their original displayed precision. Standard errors are clustered by project; coefficients are in sign-oriented control-group standard-deviation units. Foreign-minus-domestic standard errors retain the reported joint-estimation results. Original significance markers are retained: *** P < 0.01, ** P < 0.05, * P < 0.10, NS otherwise.
